Verbind met GitHub

Dit dashboard bewerkt je website door rechtstreeks te committen naar je GitHub-repository, die je daarna zelf online zet met de knop "Publiceer wijzigingen" — meestal binnen een minuut zichtbaar. Je hebt een fine-grained personal access token nodig, beperkt tot deze ene repository.

  1. Ga naar github.com/settings/personal-access-tokens/new
  2. Kies bij "Repository access" → Only select repositories en selecteer je Sojozino-repository
  3. Zet bij "Permissions" → "Repository permissions" → Contents op Read and write
  4. Genereer het token en plak het hieronder (het wordt enkel in deze browser bewaard, nergens anders naartoe gestuurd dan github.com)
Je bewerkingen zijn bewaard, maar staan nog niet op de website. Klik op publiceren wanneer je klaar bent.
